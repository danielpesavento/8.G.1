Exit ticket

180° rotation

Load a practice triangle, then rotate it 180° about the origin (angle = 180, either direction). Then answer:

Is the new triangle larger, smaller, or the same size as the original?

Explain your answer using the term "rigid transformation."

Sample answer: The triangle is the same size because a rotation is a rigid transformation. Rigid transformations only turn, flip, or slide a shape — they never stretch or shrink it, so every side length and angle measure stays exactly the same.
